
# TravelMate AI ✈️

An AI-powered travel planning web application that helps users generate personalised travel plans based on their destination, budget, starting location, and trip duration.

## Features

- AI-generated travel itineraries
- Accommodation suggestions
- Food and cafe recommendations
- Local transportation suggestions
- Estimated budget breakdown

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Google Gemini API

## Installation and Setup

1. Clone this repository.
2. Install the required dependencies:

   pip install -r requirements.txt

3. Create a `.env` file in the project folder.
4. Add your Gemini API key:

   GEMINI_API_KEY=your_api_key_here

5. Run the application:

   python app.py

6. Open http://127.0.0.1:5000 in your browser.

## Note

Travel recommendations and prices are AI-generated estimates. Actual availability and costs should be verified independently.
